5. QUICK START GUIDE
================================================================================

To Integrate KakvedaGuard into Your Project:

Step 1: Copy File
  $ cp kakveda_integration.py /your-project/

Step 2: Import
  from kakveda_integration import KakvedaGuard

Step 3: Initialize
  guard = KakvedaGuard()

Step 4: Wrap Execution
  result = guard.guarded_execute(
      prompt="user input",
      tool_name="my_tool",
      execute_fn=my_function,
      metadata={"user_id": "123"}
  )

Step 5: Configure (Optional)
  export KAKVEDA_WARN_URL=http://your-kakveda:8000/warn
  export KAKVEDA_EVENT_BUS_URL=http://your-kakveda:8100/publish
  export KAKVEDA_APP_ID=my-agent
  export KAKVEDA_ENVIRONMENT=production

Done.

8. CONFIGURATION MODES
================================================================================

Production (Mandatory Governance):
  KAKVEDA_FAIL_CLOSED=true
  KAKVEDA_AUTO_APPROVE=false
  KAKVEDA_ENVIRONMENT=production

Staging (Permissive Learning):
  KAKVEDA_FAIL_CLOSED=false
  KAKVEDA_AUTO_APPROVE=true
  KAKVEDA_ENVIRONMENT=staging

Shadow (Monitoring Only):
  KAKVEDA_FAIL_CLOSED=false
  KAKVEDA_AUTO_APPROVE=true
  KAKVEDA_ENVIRONMENT=shadow

Development (Local Testing):
  KAKVEDA_WARN_URL=http://localhost:8000/warn
  KAKVEDA_EVENT_BUS_URL=http://localhost:8100/publish
  KAKVEDA_FAIL_CLOSED=false

10. KEY GUARANTEES
================================================================================

✅ No Framework Lock-in
   Works with LangChain, FastAPI, Django, custom code, anything

✅ No Coupling
   Your agent never imports or knows about Kakveda

✅ No Exceptions to Caller
   All errors caught and handled gracefully

✅ Non-Blocking Event Publishing
   Event bus failures don't block execution

✅ Configurable Failure Modes
   Fail-closed (block) or fail-open (allow) based on env var

✅ Portable
   Single file, <50KB, only dependency is requests

✅ Production-Safe
   Comprehensive error handling, no global state, thread-safe
